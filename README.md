## Focus

```txt
I like building services that answer one clear question.

Game_Match     -> who should I play with?
Toilet_NearBy  -> where can I go right now?
Recall         -> what did I want to remember?
```

사용자가 헤매는 시간을 줄이는 서비스에 관심이 있습니다.  
기능을 많이 넣기보다, 필요한 순간에 바로 이해되는 흐름을 만드는 쪽을 좋아합니다.
